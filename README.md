# BEM FullStack Learning

Repository belajar full stack. Frontend menggunakan React dan Vite; backend menggunakan Go, Fiber, GORM, dan MySQL.

## Struktur

```text
BEM-FullStack-Learning/
├── FrontEnd/          # Aplikasi portfolio React
├── BackEnd/           # REST API Fiber + GORM
├── Materials/         # Referensi desain dashboard
├── report.md          # Analisis UI/UX dan kebutuhan CRUD
└── be_system_design.md # Rancangan backend dan API
```

Petunjuk menjalankan backend tersedia di [BackEnd/README.md](BackEnd/README.md). Buat database MySQL dan isi konfigurasi lokal berdasarkan [BackEnd/.env.example](BackEnd/.env.example).
